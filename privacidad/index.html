Política de privacidad

Información sobre el tratamiento de datos en Capitales Financieros.

Responsable y finalidad

Capitales Financieros es el sitio profesional de Sebastián Troncoso. Los datos entregados en el formulario se utilizan para responder consultas y coordinar una orientación relacionada con seguros, protección y ahorro.

Análisis de pólizas

Al iniciar voluntariamente un análisis, el documento se transmite a un servicio automatizado para generar el resultado solicitado. Las pólizas pueden contener datos personales, financieros o de salud; por ello, elimina o cubre los antecedentes que no sean necesarios antes de subirlas.

Proveedores tecnológicos

El formulario de contacto utiliza Formspree, el analizador utiliza servicios tecnológicos de procesamiento automatizado y la sección de recomendaciones utiliza Supabase para almacenar los envíos y Cloudflare Turnstile para prevenir publicaciones automatizadas o maliciosas. Estos proveedores reciben los datos necesarios para ejecutar cada función. Capitales Financieros no vende información personal.

Recomendaciones

Al enviar una recomendación, autorizas la publicación de tu nombre y opinión una vez revisados. Tu correo electrónico permanecerá privado y se utilizará únicamente para moderación, control de abuso y contacto relacionado con tu publicación. También se procesan datos técnicos limitados para impedir envíos y “Me gusta” duplicados.

Conservación y seguridad

Los datos se tratarán durante el tiempo necesario para responder la solicitud, cumplir obligaciones aplicables y resguardar eventuales responsabilidades. Se aplican medidas razonables de seguridad, sin que ningún sistema conectado a internet pueda garantizar riesgo cero.

Tus decisiones y derechos

  • Puedes usar WhatsApp sin subir una póliza.
  • Puedes solicitar acceso, corrección o eliminación de tus datos mediante los canales de contacto del sitio.
  • Puedes retirar tu autorización para comunicaciones futuras.
